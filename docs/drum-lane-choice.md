# Per-song drum lane choice — version 121

Open a song, select **Drums**, then use **Drum lanes** beneath Difficulty. Choose four or five lanes before starting. The selector is disabled during playback, preview, pause, loading and saving. The choice saves with the song on this device and in `.riffpack` backups. It is hidden on Guitar, Bass and Vocals. Existing songs default to their source layout: Clone Hero four lanes, Guitar Hero five lanes.

`quality.drumLayout` continues to describe the source. `quality.drumPlayLayout` chooses the play view. The original difficulty arrays, timing, imports, provenance, audio and exported `notes.chart` remain intact. Four-lane source Green (lane 3) moves to lane 4 for five-lane play. Red, Yellow, Blue, kick, rolls and note times remain unchanged; Orange has no additional notes. The setting cannot recover cymbal distinctions absent from a four-lane source. Five-lane sources use the existing four-pad projection when four-lane play is selected; switching back recovers the original Orange/Green notes and chords.

Play views are cached by source array and selected layout, without changing the source notes. Highway spacing, labels, pad colors, keyboard/touch controls, controller context, preview, session notes and counts use the selected view. Session scoring and roll handling receive that same layout. Layout-specific best-score keys prevent a four-lane run and its five-lane counterpart sharing a best score. Practice and video timing continue using the same song clock and note timestamps.

Validation includes desktop/mobile song selection, four/five switching, all source hits scoring at 100%, five-lane chord restoration, roll preservation, unchanged source/audio, source layout surviving saves, selected play layout surviving save/reopen and backup/import, and other instruments hiding the option. Existing drum-source, controller, difficulty, practice and update checks passed. A real-browser/device visual check remains unverified.
