# Per-song drum lane choice — versions 121–122

Open a song, select **Drums**, then use **Drum lanes** beneath Difficulty. Choose four or five lanes before starting. The selector is disabled during playback, preview, pause, loading and saving. The choice saves with the song on this device and in `.riffpack` backups. It is hidden on Guitar, Bass and Vocals. Existing songs default to their source layout: Clone Hero four lanes, Guitar Hero five lanes.

`quality.drumLayout` continues to describe the source. `quality.drumPlayLayout` chooses the play view. The original difficulty arrays, timing, imports, provenance, audio and exported `notes.chart` remain intact. Five-lane sources use the existing four-pad projection when four-lane play is selected; switching back recovers the original Orange/Green notes and chords.

Version 122 replaces v121's empty Orange slot with a five-lane conversion: Red snare, Yellow hi-hat, Blue tom, Orange cymbal, Green floor tom, plus kick. New MIDI Pro imports retain tom-marker roles and `.chart` Pro imports retain cymbal-flag roles as per-note `drumVoice` metadata. Those roles survive validation, save/reopen and `.riffpack` backups and take priority during conversion. Supported five-pad source roles are also retained during community four-pad projection. Existing saved charts lacking these roles cannot acquire verified cymbal/tom identities from their four colors alone; Find authored Drums can fetch source markers again where available.

Standard/older four-pad charts use an explicitly labeled estimated conversion. A Yellow attack separated from the previous Yellow attack by at least 1.5 beats and paired with kick becomes an Orange accent; Yellow alongside Green also becomes Orange, keeping that Green as floor tom. Green paired with kick without Yellow becomes Orange. Other Yellow stays hi-hat, Blue stays tom, and other Green stays floor tom. These are gameplay adaptation rules, not an accurate transcription of a missing drum voice. Preview the colors. The Expert chart guides shared attacks on easier levels, so the same source head retains its color; native easier-level attacks absent from Expert use their own level's context. No new attack times are inserted. Multiple cymbals that map to the same Orange pad at the same time merge into one playable head, preserving maximum roll length/dynamics.

Five-lane Orange and Green are independent inputs. Green cannot hit an Orange head or roll, and a simultaneous Orange/Green chord requires both pads. Keyboard K hits Orange; L hits Green. Touch controls and controller mappings use separate five-pad actions. Scores in this mode use a new best-score key so older runs with the shared Green/Orange scoring rule cannot become its personal best. The engine retains its legacy option for old standalone consumers; every current game session explicitly selects separate pads.

Play views are cached by source array and selected layout, without changing the source notes. Highway spacing, labels, pad colors, keyboard/touch controls, controller context, preview, session notes and counts use the selected view. Session scoring and roll handling receive that same layout. Layout-specific best-score keys prevent a four-lane run and its five-lane counterpart sharing a best score. Practice and video timing continue using the same song clock and note timestamps.

Validation includes desktop/mobile song selection and independent Orange/Green scoring, four/five switching, full song scoring, five-lane chord restoration, independent rolls, exact Pro roles through MIDI and `.chart`, role metadata through backups, estimated color consistency across difficulties, unchanged source/audio, source layout surviving saves, selected play layout surviving save/reopen and backup/import, and other instruments hiding the option. Existing drum-source, controller, difficulty, practice and update checks are included. A real-browser/device visual check remains unverified.
