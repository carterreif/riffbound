# Version 96 — Drum lanes follow the chart source

Clone Hero community drum charts use four hand lanes: Red, Yellow, Blue and Green. Kick retains its wide purple bar and separate pedal. Native Standard and Pro MIDI/.chart inputs preserve the authored pad colors on every difficulty; tom/cymbal modifiers never move a note into another color. Game conversions identified as Guitar Hero or Band Hero retain the existing five hand lanes: Red, Yellow, Blue, Orange and Green. Early guitar-only Guitar Hero sources still cannot supply authored Drums. A package being hosted in the Clone Hero catalog does not erase its claimed original Guitar Hero setlist.

The parser's source layout remains separate from its output layout. For community five-lane inputs, Orange maps to Green, and simultaneous Orange + Green becomes Green + Blue, following [Clone Hero's conversion guide](https://gist.github.com/TheNathannator/d380dd7c1e340b1d73e7af872b35ba53). Exact simultaneous collisions on one target pad merge, retaining the longest roll, loudest velocity and non-ghost accent. Distinct attack times are never snapped or dropped. [The MIDI format reference](https://thenathannator.github.io/GuitarGame_ChartFormats/Chart-File-Formats/mid-format/Tracks/Drums/) defines native red/yellow/blue/green notes separately from tom modifiers; those source colors are read directly in four-pad mode.

The highway, pad sizing, kick/roll bars, preview colors, labels and accessible instructions select the matching width. Four-pad play uses D/F/J/K and hides the fifth control; five-pad play retains D/F/J/K/L and its existing shared green/orange input. Scoring only accepts matching four-pad colors in four mode, and uses a separate best-score key. Difficulty derivation, roll tapping, audio timing, other instruments and original audio bytes retain their existing behavior.

Source layout is stored as `quality.drumLayout`, included in backups, and retained through exact-recording authored-chart reuse. Older saved community charts receive a four-pad projection when validated, including the five-to-four chord conversion. An older Pro chart that had already been expanded into kit-voice colors cannot recover its original cymbal/tom pad identity from those old notes alone; search/import that authored chart again to read its raw source colors. Older Guitar Hero charts keep five lanes. No audio is downloaded or replaced merely to reopen a saved chart.

Four-lane `.chart` rolls use their standard `S 65`/`S 66` phrase markers, with lane selection from the authored hand heads and no kick rolls. MIDI Pro/standard long note sustains remain rejected rather than becoming invented roll windows. Five-lane source sustains converted to four pads retain their roll windows in the game and backups. Four-pad exports write phrase markers and reparse them to verify the exact pad/onset/roll result; a kick roll or an ambiguous source interval requires a `.riffpack`, since a standard four-lane `.chart` cannot represent it precisely.

Title-only community audio fallbacks and verified isolated community Drum-stem estimates also receive the four-pad projection, remaining labeled estimates without any authored receipt. Guitar Hero package/stem estimates retain five-pad kit voices. An ordinary local audio estimate with no identified chart source keeps the existing five-pad layout. Exported four-pad `notes.chart` uses native pad codes and `song.ini` declares `five_lane_drums = False`; five-pad exports declare True.

Live parser checks: Youngblood's Clone Hero Pro chart for Metallica's Enter Sandman (`9a5efa898899858f27ef39fd45225f01`) produced 2,083 Expert notes using only pad indices 0/1/2/3 and kick 5. The Guitar Hero: Metallica Broken, Beat & Scarred package (`32d98dd1dc6615a5677815eccca4dfa7`) retains all six existing indices and 1,061/1,594/2,581/3,397 notes across Easy/Medium/Hard/Expert. Another matching Rock Band conversion contains a freestyle ending; that existing unsupported-chart check remains in place.

Regression coverage exercises both file formats, native/pro/five source layouts, every difficulty, chord conversion, roll/dynamics retention, all-note scoring, desktop/mobile highway centers, pad colors, no fifth control, saved audio, fresh reopening, backup, export/reimport and independently verified community Drum-stem estimates. Synthetic DOM/audio adapters validate UI behavior; physical browser QA is unavailable here. Ship Game version 96 and offline cache v96-1.
