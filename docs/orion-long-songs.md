# Version 97 — Orion audio and longer songs

The screenshot's title and artist were correct. Exact live catalog search returns Orion by Metallica, including a Neversoft Guitar Hero: Metallica conversion (`0391d102e1d9904d75f6bd356aa6d942`, icon `ghm`). Its catalog duration is 507.896 seconds. Riffbound's eight-minute recording eligibility rule discarded it before fetching the chart, so it reported “No matching recording” even though the required setlist/chart/audio existed.

Duration support is now 5 seconds to 15 minutes, with shared limits in the difficulty module used by catalog selection, chart arrangement, audio mixing, upload checks, recording comparisons, isolated-stem alignment, independent analysis and song/backup validation. Reference decoding permits bounded source padding. The 80 MB song/audio limits, 25,000 notes per difficulty, independent instrument checks, exact title/artist/version boundaries, recording alignment rules and eight-second maximum shift remain. Over-limit catalog recordings now report the 15-minute limit instead of claiming no matching song exists. Both upload-limit labels are updated.

The bundled audio iterator also stops charging local decoding/mixing time against its network deadline. Actual range requests share the existing 90-second budget; each pending fetch has a timer using the remaining budget. The timer clears before the decoded stem is yielded, and user cancellation stays attached throughout preparation. Slow local processing cannot abort the next stem merely because the preceding stem took time to prepare. Network stalls and cumulative request time still stop the download.

Live verification fetched the actual Orion MIDI and all eight selected music stems from that package, excluding preview and crowd files. The production mixer plus FFmpeg decoding adapter produced a stereo 22,050 Hz PCM WAV of 44,796,500 bytes and 507.896327 seconds, independently confirmed with ffprobe. Every stem decoded to 507.896327 seconds. The authored five-lane Drums arrangement retains 1,038 Easy, 1,630 Medium, 2,386 Hard and 2,866 Expert notes, including the ending beyond the old eight-minute boundary. The existing game-source ranking selects this drum chart ahead of the custom Guitar-only result; no per-song hardcoded mapping is needed.

The actual-file UI adapter loaded the full audio, enabled playback, saved the authored Drums and source receipt, exported/restored a byte-identical backup and reopened the saved song. Synthetic desktop/mobile tests cover the same name-only path with notes at 490/500 seconds, full-length audio, five pads, persistence and backup. Boundary tests exercise 900 seconds and reject longer songs across catalog, mixer, parser/arrangement, analyzer and library. They also cover long own-stem PCM alignment, per-instrument recording proof, local decoder pauses, cumulative network deadlines and cancellation between stems. Physical browser QA is unavailable in this environment. Downloaded music/chart containers are test data outside the site repository and are not bundled in the deployment.
