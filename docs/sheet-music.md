# Sheet-music fallback — version 120

Open **Add a song**, enter title/artist, and choose an instrument or **Whole song — all four charts**. **If a game chart is missing, search sheet music** is enabled by default and remembered on this device. Guitar Hero / Clone Hero results have priority. Only missing requested parts are sent to the sheet-music lookup. Existing authored parts are preserved. If no score can supply a part, available audio can still produce an explicitly labeled estimate.

The automatic source is Internet Archive's public advanced-search and metadata APIs. The query looks for MusicXML/XML records by title and creator. It checks up to four exact normalized title/creator matches and two downloadable score files per item. Downloaded MusicXML must independently match the requested title and creator. Restricted/private files are skipped; blocked responses produce recovery messages. There is no sign-in, paid-score extraction, proxy, arbitrary page scraping or PDF recognition. This is a bounded catalog lookup, not a promise that every published song has a downloadable score. A shared 15-second deadline, cancellation and streamed byte limits bound each search.

You may instead select **Sheet music file (optional)**. An uncompressed `.musicxml`/`.xml` file up to 4 MB converts locally without a score-service request. No audio is required: available score parts can be saved, previewed, reopened and backed up as chart-only songs. Attach matching audio later to play. When audio is supplied, the score's full duration must be within 3 seconds or 2% of that recording and all note positions must pass the normal song validation. Duration agreement is not waveform verification. Imported score parts use `sheet-music-timing-review-v1`, with `timingVerified: false`, and the existing instrument timing tools offer review/adjustment. Score sources and warnings survive `.riffpack` backups; the original score file is not embedded in the backup.

The reader supports score-partwise MusicXML, explicit initial tempo, tempo changes, time signatures, pickup measures, rests, parallel voices via backup/forward, chords, concert-pitch transposition and contiguous ties. Expert follows written note attacks. Easy, Medium and Hard are derived by the existing difficulty reducer; no new attacks are invented. Grace/cue notes are omitted and reported. Repeats, numbered endings, playback jumps, shorthand multiple rests, ambiguous percussion and supported-part ornaments requiring expansion are rejected for that part with instructions to export unfolded notes. Missing initial tempo, malformed XML, entity declarations and invalid durations/pitches fail explicitly. Unsupported parts can contribute timing but cannot become another instrument's chart.

Guitar, Bass and Vocals map ascending pitches across five lanes, adapting the notation to the game rather than claiming original Guitar Hero fingering. Drum sounds use MusicXML's MIDI percussion assignments (1–128, converted to MIDI's 0–127) or explicit supported kit names: Red snare, Yellow hi-hat, Blue tom, Orange cymbal, Green floor tom, plus kick. Unknown staff positions are not guessed. Sheet-derived Drums use five lanes; existing Clone Hero drum charts retain their four-lane layout. Piano-only notation does not create Guitar, Drums or Bass parts. Only supported parts actually present are included.

Validation covers all four instruments, all difficulties, drum assignments, bass-drum/choir-bass classification, tempo changes, ties, rests/chords/voices, accompaniment tempo, partial/unsupported scores, exact source identity, file/response size limits, cancellation, opt-out, game-chart priority, partial audio fallback, audio timing provenance, real Add a song handlers, saving/reopening and backup round trips. Catalog HTTP responses are deterministic test adapters; real Internet Archive availability/CORS and browser playback were not verified in this environment. The uploaded-score path is independently tested without network access.
