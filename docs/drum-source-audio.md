# Drum source audio and colors — version 94

Future audio uploads now use exact title/artist searches, bounded Guitar Hero setlist queries and a Clone Hero instrument query for missing parts. Previously these narrower searches were limited to song-name additions. Filename or form identity is required; a track number alone cannot identify a recording.

Authored Drums remains the first choice. Source audio must verify against the upload before importing its notes, colors and arrangements. Version 98 also accepts recording proof from a sole full-song file for an already-parsed Drum track; see clone-drum-recording.md. This is not isolated Drum-stem evidence. A Guitar match cannot verify Drums. Early guitar-only games cannot supply Drum audio or notes.

If a supported Drum arrangement cannot be imported, the lookup can independently inspect later-game/community packages for named `drums` or `drums_1` through `drums_4` audio. Full mixes and Guitar, Bass or Vocal stems cannot pose as this reference. Stable correlation in separated recording windows must establish a constant offset within eight seconds; incompatible recordings, repeats, drift, missing files and weak evidence are declined. The original full-band recording is not replaced.

For this fallback only, source audio is decoded to mono 22,050 Hz PCM with stereo phase-cancellation protection. Multiple kit stems are added incrementally, then their verified padding is aligned to the upload’s duration before the independent Drum analyzer runs. Peak scaling only prevents clipping; no notes or colors are borrowed from another instrument. The analyzer receives percussion without Guitar/Bass/Vocal masking. Source-stem jobs bypass recording-hash templates intended for the original full mix, while saved evidence retains the original recording identity. Source PCM is temporary; only the estimated notes and compact recording/source evidence survive the job. Existing four-file, eight MB per-file and 24 MB reference budgets, request deadline, cancellation and access-block rules remain.

Song-name additions can likewise analyze their own package’s Drum stems while saving the package’s full music for playback. Because both originate from that package, this path records package provenance rather than an independent upload waveform claim. Authored parts retain their own arrangements. Without Drum stems, the full-song estimator remains available and explicitly estimated.

Estimated results never receive an authored import hash or another part’s chart reference. Uploaded playback bytes, audio SHA-256, neighboring charts and manual edits outside the requested part remain intact. Save/reopen and riffpack backups retain the result and its source evidence, without retaining the temporary stems. The uploaded-song waveform still describes the uploaded audio.

Ten new regressions run real SNG/MIDI parsers, recording matching and Drum analysis on desktop/mobile adapters. A 27-second percussion fixture with added Guitar tone retains all 36 labeled strikes, all six correct colors and original onset timing after matching a source padded by two seconds. Tests cover multiple stems, stereo inversion, resampling, fractional shifts, peak bounds, wrong recordings, other-instrument/full-mix refusal, host blocks, independent part queries, original bytes, backups, template isolation, silent-stem fallback and same-package Drum analysis. No physical-device test is claimed.

A live future-upload lookup also fetched Creeping Death’s actual Guitar Hero: Metallica Drum chart and verified it against its four own Drum audio files at zero shift. Its 1,059 Easy, 1,805 Medium, 2,321 Hard and 2,786 Expert notes were retained. Reference decoding in that live check used the actual source’s FFmpeg-decoded PCM, with the production waveform matcher.

Finding matching song audio alone cannot guarantee every drum color. Where a genuine Drum chart or usable isolated percussion source is absent, estimates can still confuse dense music; the source and estimated status remain visible. No new commercial song audio is included in the published game.

Release validation: all ten new source checks pass. The 163 affected authored/source, chart, backup and offline/update checks passed 162, with one optional reference WAV skipped. Final title-search, backup and offline/update checks passed 75 of 76, with the same optional WAV skipped. Runtime syntax, local asset paths, unique HTML IDs and whitespace checks pass.
