# Version 99 — Stinkfist by Tool, actual Clone Hero Drums

Live Enchor exact title/artist and targeted Drum searches return a Wagsii Guitar-only Stinkfist package (4b3dee1a1435dc6690e67f714c90573a). Its downloaded metadata has diff_drums=-1 and notes.chart has no Drum sections. Changing the instrument filter cannot produce Drum notes from that package. A separate public Clone Hero conversion in the community METAL PACK contains DenVaktare's actual Drum track, omitted by that search index.

The supplemental community-pack registry now includes this verified source. It is considered alongside exact matching catalog candidates when Drums is requested; existing Guitar Hero priority, instrument boundaries and recording matching remain. The source is identified by the digest of its MIDI and INI, with its actual Drive provenance URL, rather than pretending it lives on the Enchor CDN. The registry is deliberately limited to reviewed sources and does not claim to search all community folders.

The ZIP reader requests only notes.mid, song.ini and (when needed) song.ogg entries by exact byte ranges from the public pack. It never downloads the 1,070,407,649-byte archive. File names, compression, encryption flag, bounded compressed/uncompressed sizes, response lengths and SHA-256 receipts are checked before use. Invalid ranges, a whole-archive response, changed packages, corrupt data, oversized inflation, cancellation and access/quota failures reject the source. Cross-origin download headers permit public browser range requests; Content-Range can be hidden, so exact bounded length and file receipts remain enforced. Browser raw-deflate support is required; unsupported decoders retain the existing clear fallback.

The MIDI importer also distinguishes supported static Drum activation fills from Big Rock Endings. The documented markers 120–124 can mean either. Interior fill windows containing actual Expert hits and later authored heads retain those existing notes; marker notes add no hits. An EVENTS [coda] marks the start of a true Big Rock Ending and remains unsupported, as do uncharted/final freestyle windows and Guitar endings. This source has 15 interior activation fills. Its authored Drums preserve 360 Easy, 708 Medium, 1,119 Hard and 1,600 Expert notes, native Red/Yellow/Blue/Green plus kick, and its variable tempo map. No Guitar notes become Drums.

Uploaded audio is independently compared with the package's sole full recording under version 98's bounded Drum recording proof. Original upload bytes remain unchanged. Title-only additions retrieve this chart's own full audio. The source audio is 317.182789 seconds; a different 313.119456-second studio recording independently matches five windows at a constant -3.325533-second offset. Matching that recording moves the authored notes earlier without changing colors/difficulties. Other recordings continue to require their own waveform match.

Eight new deterministic tests exercise the production bounded ZIP reader, correct/hidden ranges, raw deflate, complete receipts, corruption/name/hash/codec/encryption/size refusals, cancellation/host blocks, registry identity and MIDI fill/coda boundaries. Across affected suites 152 tests pass with one optional original-reference-WAV check skipped. Syntax, static/offline assets, IDs and whitespace checks pass. Actual-file desktop/mobile UI/audio adapters verify the live source chart, upload waveform proof, original audio, four pads, backup/reopen playback and title-only chart-plus-audio retrieval. The full-source upload retains all four authored levels without an analyzer job; name-only playback saves a 27,975,572-byte stereo WAV from the same source package. Physical browser QA is unavailable. Downloaded source MIDI/INI/music remain outside the repository and deployment; only source metadata and reader code ship.

Use Game version 99 / offline v99-1, open Stinkfist, select Drums and choose Find authored chart, or reupload the original recording with community lookup enabled. Add song with Stinkfist / Tool / Drums also retrieves the chart and its matching audio without an upload.
