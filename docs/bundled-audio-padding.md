# Version 95 — Broken, Beat & Scarred audio

Two independent failures affected title-only submissions of Metallica's song. Catalog/package identity treated `&` and `and` differently, and the exact catalog name index required the original comma. Title identity now preserves the conjunction as the word `and`; a missed exact conjunction query uses the existing bounded general query early, before spending time on empty game/instrument searches. Catalog and downloaded metadata still require the same title words, artist, version and recording rules. Live versions, different artists and missing conjunctions remain distinct. Uploaded audio still requires each requested instrument's own recording proof.

The retrieved Guitar Hero: Metallica package (`32d98dd1dc6615a5677815eccca4dfa7`, Neversoft) reports a chart length of 386.85 seconds, while all eight music stems decode to 397.159 seconds. Its added tail contains near-silence and low-level encoding noise. The mixer now accepts at most 15 seconds of additional end padding, provided every channel's 100 ms window after the existing 750 ms end tolerance stays below a 0.001 peak and 0.00025 RMS. It rejects late musical attacks, non-finite samples, audible tails, shorter recordings and excessive padding. It retains time zero and the first 750 ms beyond the catalog end; it changes no chart notes. Normal duration differences within 750 ms behave as before. Cancellation remains active throughout the scan.

Live verification recovered the package from `Broken Beat and Scarred` / `Metallica`, parsed its actual MIDI and downloaded/unmasked every music stem. FFmpeg decoded all eight stems; the production mixer produced a 387.6-second stereo 22,050 Hz PCM WAV (34,186,364 bytes), independently confirmed with ffprobe. The actual Drum arrangement has 1,061 Easy, 1,594 Medium, 2,581 Hard and 3,397 Expert notes. Synthetic DOM/audio adapters exercise playback, chunk-storage persistence, backup and fresh reopening; physical browser testing is unavailable in this environment. No fetched song/audio assets are included in the site bundle.

Regression tests cover title/package boundaries, uploaded-recording proof, desktop/mobile submission and playback, multiple sample rates, preserved attacks, faint noise, musical tails, isolated late pulses, invalid samples and existing audio limits.
