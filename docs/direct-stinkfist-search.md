# Version 100 — Direct title-only Stinkfist Drum discovery

The user reported no match from Find chart & audio after version 99. The attached screenshot was not available at its supplied local path, so its exact inputs/client version could not be inspected. The public Site and scripts were confirmed to serve version 99, with the supplemental registry present. The live browser-global lookup succeeded for exact Stinkfist / Tool / Drums, so this work does not claim to have reproduced the user's precise failure.

An observed weakness was that version 99 consulted the main catalog, setlist queries, missing-instrument queries and a broad fallback before adding an already reviewed supplemental Drum source. A slow/unavailable catalog could exhaust lookup before consulting that source. Name-only single-part Drums searches now match the local reviewed registry first. An exact known source goes directly to its own chart package, independent of those catalog requests. Other titles, artists, instruments, Whole song and audio-upload scopes retain their ordinary catalog/recording rules. Identity, supported-part parsing, source byte receipts and package/audio boundaries remain mandatory.

Chart download failures now state that a matching source was found but could not be downloaded, retain the underlying reason and show an HTTP status when available. A source-access block still ends the attempt without trying alternative hosts. Cancellation and wrong packaged identities cannot become successful results.

Ten new tests cover known-source lookup with an unavailable main catalog, explicit blocked-source messages, cancellation, wrong source identity, different titles/artists, other instrument scopes, desktop/mobile Find chart & audio and browser-global script loading independent of Node module resolution. Across affected catalog, ZIP, title/audio, offline/update and storage suites 108 tests pass; one optional original-reference-WAV check is skipped. Syntax, asset paths, unique IDs, version agreement and whitespace checks pass.

Live verification used exact Stinkfist / Tool / Drums. The production lookup made zero catalog requests and six bounded requests to the existing public source for MIDI, INI and audio. It retained 360 Easy / 708 Medium / 1,119 Hard / 1,600 Expert authored Drum notes and native four-pad colors. The actual-file UI/audio adapter saved playable, same-package audio as a 27,975,572-byte stereo WAV lasting 317.182857 seconds, without an estimator job. Browser-global loading was tested in a JavaScript VM; a physical browser session was unavailable. Downloaded music/chart material stays outside the repository and published assets.
